# Belarus University Guide Bot

🇧🇾 Телеграм-бот для абитуриентов белорусских университетов.

## Описание

Бот помогает абитуриентам:
- Рассчитать проходной балл по результатам ЦТ/ЦЭ и среднему баллу аттестата
- Подобрать ВУЗы и специальности на основе проходных баллов 2024 года
- Узнать ТОП востребованных специальностей
- Получить консультацию от ИИ-ассистента
- Записаться на персональную консультацию к куратору

## Возможности

1. **Калькулятор баллов** — пошаговый расчёт итогового проходного балла
2. **Подбор ВУЗа** — поиск специальностей по вашему баллу (бюджет/платное)
3. **ТОП специальностей** — самые востребованные направления
4. **ИИ-консультант** — ответы на вопросы о поступлении
5. **Запись на консультацию** — связь с администратором

## Технологический стек

- Python 3.10+
- Aiogram 3.x (асинхронный фреймворк для Telegram ботов)
- FSM (машина состояний для калькулятора)
- JSON (хранение данных о ВУЗах)
- g4f (AI-консультант)
- python-dotenv (переменные окружения)

## Установка

### 1. Клонирование или скачивание проекта

```bash
cd beluniversitiebot
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Откройте `.env` и заполните:

```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_ID=ваш_telegram_id (необязательно)
ADMIN_USERNAME=ваш_username_без_@ (необязательно)
```

#### Как получить BOT_TOKEN:

1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Придумайте имя бота (например: Belarus University Bot)
4. Придумайте username бота (должен заканчиваться на `bot`, например: bel_uni_bot)
5. BotFather выдаст токен — скопируйте его в `.env`

#### Как узнать свой ADMIN_ID:

1. Найдите бота @userinfobot в Telegram
2. Отправьте ему любое сообщение
3. Он вернёт ваш ID (число, например: 123456789)

## Обновление данных о ВУЗах

Файл `data/universities_2024.json` содержит пример данных. Для актуализации:

1. Откройте файл в редакторе
2. Каждая запись имеет структуру:

```json
{
    "university": "Белорусский государственный университет",
    "faculty": "Факультет прикладной математики и информатики",
    "specialty": "Программная инженерия",
    "city": "Минск",
    "budget_passing_score_2024": 350,
    "paid_passing_score_2024": 280,
    "subjects": ["Математика", "Физика/Информатика"],
    "demand_level": "high",
    "description": "Одно из самых популярных направлений"
}
```

3. Добавьте или измените записи согласно официальным данным приёмной комиссии 2024 года
4. Сохраните файл

> ⚠️ **Важно**: Проходные баллы в этом проекте — примерные. Всегда проверяйте актуальную информацию на официальных сайтах ВУЗов!
