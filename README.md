Belarus University Guide Bot Telegram-бот для абитуриентов Беларуси. Помогает рассчитать баллы (ЦТ/ЦЭ + Аттестат), подобрать подходящий ВУЗ на основе проходных баллов 2024 года и получить консультацию от ИИ

Основные функции  
Калькулятор баллов: Пошаговый ввод результатов тестирования и среднего балла аттестата.

Анализ шансов: Мгновенная проверка, в какие ВУЗы и на какие специальности проходит пользователь.

ТОП специальностей: Список самых востребованных направлений по базе данных.

ИИ-консультант: Интеграция с GPT (через библиотеку g4f) для ответов на вопросы о поступлении.

Запись на консультацию: Прямая связь с администратором (куратором) проекта.

Технологический стек Язык: Python 3.10+

Фреймворк: Aiogram 3.x (Asynchronous Telegram Bot API)

AI Engine: g4f (Free GPT-4 API)

Хранение данных: JSON (для базы ВУЗов)

Состояния: FSM (Finite State Machine) для работы калькулятора.

pip install aiogram g4f
